How the agent works

  1. The wallet signs a delegationIt holds the action, the limit, the allowed verifiers and an end time. You approve it in the wallet.
  2. The agent shows it to a verifierThe agent signs each presentation with its own key. It works without you.
  3. The verifier checks 3 signaturesThe issuer signed the credential. The wallet signed the delegation. The agent signed the presentation.
Format of the delegation

The delegation is a Delegate SD-JWT (draft-ietf-oauth-delegate-sd-jwt-00). It lists the agent key, the allowed action, a limit, an end time and the verifiers.

Trusted lists of the verifiers

The verifiers load the trusted lists of the business wallet over HTTP.
